Guia Rápido: TikTok LIVE Studio, OBS Studio e PRISM Live

Os arquivos .WEBM do Effect Battle já vão recortados com fundo transparente. Escolha abaixo onde você faz suas lives:

1. TikTok LIVE Studio (PC)
  1. Em Effect Battle, clique em Baixar (.WEBM) no efeito desejado.
  2. No TikTok LIVE Studio: Adicionar fonte → Vídeo (ou Imagem para molduras .PNG).
  3. Selecione o arquivo baixado — ele já entra transparente sobre sua câmera!
  4. Para alertas automáticos, adicione uma fonte Link / Navegador com o link da aba Events → Tela de Sobreposição.
2. OBS Studio (PC)
  1. Clique em + → Fonte de Mídia e escolha o .WEBM baixado.
  2. Marque "Reiniciar reprodução quando a fonte ficar ativa" e "Desligar fonte quando não visível (Shutdown source)" para economizar memória.
  3. Para Rankings e Triggers automáticos, use + → Navegador com os links copiados do painel.
3. PRISM Live Studio (Android / PC)
  1. No PRISM Android, use My Studio → Widget → Web (até 4 widgets na tela).
  2. Em Effect Battle, toque em Link Web (PRISM) e cole lá — assim o .WEBM entra transparente na câmera do celular!
  3. Molduras .PNG entram em My Studio → Media.
  4. Para transmitir ao TikTok pelo PRISM, conecte sua chave em Custom RTMP (ou use Câmera Virtual no PC).
